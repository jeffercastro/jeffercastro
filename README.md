## About Me

I am a **Software Engineer** specializing in **Quality Assurance (QA) and Test Automation Architecture**. 

My mission is to help engineering teams release features faster, with higher confidence, and with zero critical bugs reaching end-users. I design reliable, automated test suites that integrate directly into continuous deployment pipelines (CI/CD), drastically reducing manual QA time and catching potential production issues early in the software development lifecycle.

- **Primary Stack:** TypeScript, JavaScript, Java, Python, SQL
- **Core Specialization:** End-to-End (E2E) UI Automation, API Testing, Database Validation
- **Methodology:** Scalable framework design, maintainable Page Object Model (POM), cross-browser coverage, and stable CI/CD pipelines
- **Location:** Latin America (Open to Global Remote / Relocation)

## Engineering Philosophy

```text
┌─────────────────────────────────────────────────────────────────────┐
│                                                                     │
│   "A test suite is not a checkbox — it's a living system that       │
│    must be as well-architected as the product it validates."        │
│                                                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                     │
│   • Shift-Left Testing     → Catch defects at API/contract level    │
│                               before they even reach the UI.        │
│                                                                     │
│   • Zero Flaky Tolerance   → Every flaky test erodes trust.         │
│                               Fix locators, isolate state, no loops.│
│                                                                     │
│   • Actionable Reports     → If a failure takes >30s to triage,     │
│                               the reporting architecture is broken. │
│                                                                     │
│   • Data Independence      → Each test sets up and tears down       │
│                               its own isolated test data.           │
│                                                                     │
└─────────────────────────────────────────────────────────────────────┘
```
